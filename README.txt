CICLY — versão refeita fiel aos prints (Telas 1 a 11)

Esta versão usa os próprios prints como base visual para preservar:
- ilustrações originais
- ícones originais
- posições
- cores
- fontes
- sombras

Sobre os prints foram adicionados controles reais:
- cadastro
- navegação
- escolhas
- contador
- sintomas

Para publicar:
1. Extraia o ZIP.
2. Envie todos os arquivos e pastas ao GitHub.
3. O Vercel atualizará automaticamente.


CORREÇÕES DESTA VERSÃO:

- Tela 11: sintomas agora permitem múltipla escolha.
